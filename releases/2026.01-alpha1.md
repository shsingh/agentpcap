# 2026.01-alpha1 — gate report

Release gate: [the 2026.01-alpha1 gate in ADR-0002](https://github.com/shsingh/agentpcap/blob/main/docs/adr/0002-release-gates.md#2026-01-alpha1--mvp-the-stdio-class-end-to-end)

Scenario: one lab host, one MCP client, one local MCP server launched
over stdio. The pipe collector captures the JSON-RPC frames; the ledger
appends; `report` answers "who called what with which capabilities".

The tool message: the `tools/call` request carries the tool name (`read`)
and its arguments; the reply carries the result text. Every record bears
`schema_version "1.0"` and the chained `prev` hash of the prior record.

## Blockers outstanding

None. All five alpha1 issue blockers closed: #12 (ledger), #14
(fixtures), #13 (CLI), #11 (tap and scenario — PRs #61, #62).

## What this release does not claim

The wire class (socket, TLS sessions, reassembly), the export and diff
CLI paths, and the throughput measurements belong to `2026.01-alpha2`
and `2026.01-rc1`. No claims beyond the gate.
